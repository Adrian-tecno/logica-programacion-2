# 🌡️ Lógica de Programación 2 - Conversor de Temperatura

¡Bienvenido a este repositorio! Este proyecto consiste en un programa desarrollado en JavaScript que interactúa con el usuario para solicitar una temperatura en grados Celsius (°C), valida la entrada y realiza la conversión a grados Fahrenheit (°F) y Kelvin (K).

---

## 🚀 Funcionalidades

- **Entrada interactiva:** Solicita los datos al usuario mediante una ventana emergente (`prompt`).
- **Validación robusta:** Detecta si la entrada no es de tipo numérico o si el usuario ingresa espacios en blanco, mostrando un mensaje de error y volviendo a solicitar el dato.
- **Cálculo preciso:** Aplica las fórmulas de conversión estándar para Fahrenheit y Kelvin.
- **Salida doble:** Muestra la información directamente por alertas en pantalla y detallada en la consola del navegador (`console.log`).

---

## 🧪 Casos de Prueba

El programa fue probado con las siguientes entradas especificadas en la práctica:

| Entrada (°C) | Grados Kelvin (K) | Grados Fahrenheit (°F) |
| :----------: | :---------------: | :--------------------: |
|     `45`     |     `318.15`      |         `113`          |
|     `14`     |     `287.15`      |         `57.2`         |

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica enriquecida con **Bootstrap 5** para la vista de presentación.
- **JavaScript (ES6):** Manejo de bucles (`while`), validaciones (`isNaN`, `trim`, `parseFloat`) y cálculos matemáticos.
